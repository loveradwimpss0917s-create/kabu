# StockEdge 優位性検証の結果まとめ（2026年8月時点）

このドキュメントは、約3,575銘柄・10年分（観測数 約710〜770万件）のデータで実施した
一連の仮説検証の結果を、**都合の良し悪しに関わらず**記録したものである。

結論を先に書く。

> **売買コストを差し引いて実際に使える「買いの優位性」は、検証した8つの仮説すべてで
> 見つからなかった。頑健に確認できたのは「特定のスコア帯が市場平均に劣後する」という
> 守りの知見のみである。**

この文書の目的は、同じ検証を繰り返さないこと、そして将来「優位性を見つけた」と
考えたときに、その主張が過去に否定された仮説の焼き直しでないかを照合できるようにすることである。

---

## 1. 検証環境（測定器）

| 項目 | 内容 |
|---|---|
| ユニバース | 東証の普通株 約3,575銘柄（ETF/REIT/ファンド等を除外） |
| 期間 | 2016-10 〜 2026-07（約10年） |
| 観測数 | 約710〜770万件 |
| データ源 | Yahoo Finance（Supabase `bt_prices_cache` にキャッシュ） |
| ベンチマーク | 同日・同ホライズンの全銘柄等加重平均リターン |
| エントリー | 判定日の翌営業日の始値（ルックアヘッド防止） |
| 有意性判定 | 日付単位の事前集計 ＋ 移動ブロック・ブートストラップ（ブロック長40営業日） |

### 統計手法の較正履歴（重要）

測定器そのものに2度、過大検出の欠陥が見つかり修正した。**これを直す前の結論は信用できない。**

**(1) 時系列重複の無視（修正済み）**
20営業日リターンは連続する最大19営業日が同じ価格変動を共有するため、日付を独立に
リサンプリングすると実効サンプル数を過大評価する。合成データで実測したところ、
効果ゼロのデータに対する誤検出率が **57%**（本来5%）に達していた。
移動ブロック・ブートストラップ（ブロック長40）で **14%** まで改善。

**(2) 銘柄横断方向の不確実性の取りこぼし（修正済み）**
ブロック・ブートストラップは日付方向しかリサンプリングしないため、
「どの銘柄が抽出されたか」の不確実性を捉えられず標準誤差を約23%過小評価していた。

- 独立試行から実測した真のSE = 0.0928% に対し ブートストラップSE = 0.0713%
- 補正なしの誤検出率 = **23%**（本来5%）
- 信頼区間の拡大倍率ごと: 1.0倍→23% / 1.2倍→10% / 1.3倍→8% / **1.5倍→0%**
  （検出力はいずれも100%を維持）

→ **信頼区間は点推定を中心に1.5倍へ拡大**して判定する。

なお(2)の調査中、一時はスクリプトのバグを疑ったが、真因はテスト用合成データの
乱数生成器（線形合同法）が持つ系列相関（lag1自己相関 -0.0124）が人工的な反転を
生んでいたことだった。mulberry32 + Box-Muller法に替えるとスプレッドは +0.023%
（ほぼゼロ）となり、分析ロジック自体は正しいことを確認している。
**合成データで測定器を検証する際は、乱数生成器の品質を必ず疑うこと。**

## 2. 中核仮説の検証結果 — スコア帯と将来リターン

「calcTradeScoreが高い銘柄はその後リターンが高い」という中核仮説の検証。

判定: **EDGE_NOT_CONFIRMED**（コスト差引後）

| スコア帯 | 表示 | 20日 市場平均比 | 95%CI（1.5倍較正後） | 評価 |
|---|---|---|---|---|
| 90-100 | 最上位帯 | -0.05% | [-0.51, +0.39] | 市場平均と区別できない |
| 75-90 | 上位帯 | -0.04% | [-0.30, +0.18] | 市場平均と区別できない |
| 50-75 | 劣後帯(中位) | -0.33% | [-0.48, -0.21] | **有意に劣後** |
| 30-50 | 劣後帯(下位) | -0.35% | [-0.58, -0.14] | **有意に劣後** |
| 0-30 | 最下位帯 | -0.37% | [-1.08, +0.31] | 点推定は最下位だが統計的に確定せず |

**単調性は良好**（Spearman ρ=0.9）。スコアは銘柄を正しく順位付けしている。

### 訂正の訂正: 「+0.25%のグロス優位性」は測定アーティファクトだった

一時、この文書は「上位帯には+0.25%のグロス優位性があるが往復コストが食い尽くしている」
と記載していた。これは誤りだったため訂正する。経緯を隠さず記録する。

`run.mjs`は「コストを払って売買する戦略」対「コストを払わず持ちっぱなしの市場平均」を
比較する設計であり（`frictionOnlyPct()`が戦略側のみに往復0.30%を課す）、上記スコア帯別
表の数値はコスト差引後である。ここまでは正しい。そこで一度、コストを戻した**グロスの**
数値を`run.mjs`の集計から取り出したところ、75-90帯で+0.256%という値が得られ、
「コストが優位性を食い尽くしている」という訂正を行った。

しかしこの+0.256%は**観測行ごとの平均**であり、上位帯の銘柄数が多い日（強気相場）に
重みが偏っていた。`backtest/hypothesis-holding-period.mjs`で日付ごとに等しく1票とする
**日ごとの平均**（実際に毎日同じ資金を投じる取引に対応する指標）を計算し直したところ、
20営業日でのグロス超過は**-0.006%**（信頼区間 [-0.45, +0.33]、市場平均と区別できない）
となった。日ごと平均と行ごと平均の差は+0.254%で、これは`run.mjs`が報告していた
+0.256%とほぼ完全に一致する。**つまり「+0.25%の優位性」は実在せず、集計時の重み付けが
生んだ見かけ上の数字だった。**

保有期間を20/40/60/120営業日に延ばしても、日ごと平均でのグロス超過が統計的に有意に
プラスになることは一度もなかった（120日でも点推定+0.43%、信頼区間[-1.35, +1.49]で
0をまたぐ）。したがってコスト差引前の時点で優位性を確認できておらず、
「保有期間を延ばせばコストに勝てる」という仮説も成立しなかった。

**最終的な結論: 上位帯（75点以上）に市場平均を上回る力があるという主張は、
1〜120営業日のいずれの保有期間でも支持されなかった。** 上位帯の価値は
「劣後しないこと」にとどまる。

### 注意: 0-30帯の扱いを訂正した
較正前は0-30帯を「市場平均を明確に下回る」と表示していたが、1.5倍較正後は
信頼区間が0をまたぐため、この主張は実測に支えられていない。
アプリの文言を「点推定は最下位だが統計的には確定できない」に修正済み。

### 教訓: 集計の重み付けは常に問い直すこと
グループ別の平均を計算する際、「観測行ごと」と「時間単位（日）ごと」では
全く違う数字になりうる。前者は出現頻度が偏るイベント（強気相場で上位帯が
大量発生する等）に暗黙に重みを与えてしまう。「実際に毎日同じ資金を投じたら
どうなるか」という取引実務の問いに対応するのは後者であり、以後の検証は
日ごとの平均を基本とする。

## 3. 新仮説の検証結果（すべて否定）

| # | 仮説 | 判定 | 要点 |
|---|---|---|---|
| 1 | PEAD（決算後ドリフト） | 継続は検出されず | 逆に**強い反転**を検出。測定器が機能することの確認にはなった |
| 2 | モメンタム(12-1) | EDGE_NOT_CONFIRMED | Q5-Q1スプレッド -0.04%、単調性 ρ=-0.1（無相関） |
| 3 | セクター相対強度 | EDGE_NOT_CONFIRMED | top-bottom -0.01%、単調性 ρ=-0.5 |
| 4 | rev5（短期リバーサル） | 実用性なし | 詳細は下記 |
| 5 | rev20（1ヶ月リバーサル） | EDGE_NOT_CONFIRMED | -0.23%、CI [-0.82, +0.40] |
| 6 | vol60（低ボラティリティ） | EDGE_NOT_CONFIRMED | +0.17%、CI [-0.89, +1.30] |
| 7 | turnover（低流動性） | EDGE_NOT_CONFIRMED | -0.31%、CI [-0.84, +0.20] |
| 8 | 上位帯×保有期間の延長 | EDGE_NOT_CONFIRMED | 1〜120営業日いずれもコスト前から非有意。詳細は上記2章 |

### PEADについて（1）
実際の決算発表日・サプライズ(SUE)データは無料では取得できないため、
「価格急変(|当日リターン|≥5%)＋出来高急増(平常の2倍以上)」を代理指標とした。

結果は仮説と**逆**だった。急騰後は市場平均に対し20日で -1.02%、急落後は +0.44%。
つまり継続ではなく反転が起きている。ただしこれは決算固有の効果とは言えない
（決算以外の材料によるジャンプも大量に混入するため）。

**この検証の価値は「測定器が本物のシグナルを検出できる」ことを示した点にある。**

### rev5の実用性判定について（4）
事前登録した20日ホライズンでは非有意だったが、1日・5日では信頼区間が0を除外し、
単調性 ρ=-0.9・サブ期間3/3一致という兆候を示したため、実用性を精査した。

結果は**実用にならない**:

| コスト前提（往復） | Q1ロングの1回転純損益 | 年換算 | 統計的にプラスか |
|---|---|---|---|
| 0.00%（実現不可） | +0.08% | +4.0% | ✅ |
| 0.05% | +0.03% | +1.5% | ❌ |
| 0.10% | -0.02% | -1.0% | ❌ |
| 0.30%（現行前提） | -0.22% | -11.0% | ❌ |

さらに致命的なのは、**実際に売買できる銘柄では効果自体が消える**こと:

| 流動性ティア | Q1超過リターン（コスト前） | 95%CI |
|---|---|---|
| 全銘柄 | +0.080% | [+0.008, +0.164] |
| 売買代金 上位50% | +0.024% | [-0.070, +0.124] |
| 売買代金 上位20% | -0.009% | [-0.106, +0.104] |
| 売買代金 上位10% | -0.017% | [-0.110, +0.104] |

効果は流動性の低い小型株にのみ存在し、実際にスリッページを気にせず売買できる
銘柄群では統計的に消滅する。学術文献でも知られる典型的なパターンである。

## 5. この結果から導かれる設計方針

### やってはいけないこと
- **「買い」「強い買い」のように上昇を予測する表示**。実測と矛盾する
- 同じデータで新しいファクターを探し続けること。試行を重ねるほど偶然の当たりを
  引く確率が上がる（rev5がまさにその典型で、一見有望だったが精査すると消えた）
- 事前登録した検定と違う条件で「有意だった」と主張すること

### 実測に支えられていること
- スコアの**順位付け**は妥当（単調性 ρ=0.9）
- **30-75点の帯は市場平均に有意に劣後する** → 避けることには根拠がある
- 75点以上は「劣後しない」帯。上回る根拠はない
- **売買コストが支配的**。年50回転・往復0.30%なら年-15%の確定的な負け

### アプリが提供できる正直な価値
「何が上がるかを当てる」ことではなく、
**「確実に負ける行動を避けさせる」**ことに価値の重心を置く。

具体的には、劣後帯の回避、売買コストの可視化、ポジションサイジングによる
リスク管理、そして**今後の実運用データを蓄積してアウト・オブ・サンプル検証を
可能にすること**。ここまでの検証はすべてイン・サンプルであり、将来データでの
追試を経ていない点は明記しておく。

## 6. 再現方法

すべてGitHub Actionsから手動実行できる（CLI不要）。

| ワークフロー | 内容 |
|---|---|
| バックテスト用ユニバース・キャッシュ構築 | `step=universe` → `step=cache` の順で実行しキャッシュを構築 |
| バックテスト | 中核仮説（スコア帯と将来リターン） |
| 仮説検証 PEAD | 決算後ドリフトのサニティチェック |
| 仮説検証 モメンタム12-1 | クロスセクショナル・モメンタム |
| 仮説検証 セクター相対強度 | 業種の相対強度（事前に業種分類キャッシュ構築が必要） |
| 仮説検証 ファクター一括 | rev5 / rev20 / vol60 / turnover |
| 仮説検証 rev5実用性判定 | コスト・流動性別の実用性 |
| 仮説検証 上位帯×保有期間 | 保有期間20/40/60/120営業日での上位帯優位性（日ごと平均・行ごと平均の両方を出力） |

結果は `backtest/results/` に自動コミットされる。
